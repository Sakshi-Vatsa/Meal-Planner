DR. SHIKHA MEAL PLANNER — BRAND UPDATE

This package rebrands the already-built, privacy-safe Dr. Shikha meal archive.
It keeps the full existing meal library, recipe videos, responsive interface and app icons.

Update your existing GitHub repository:
https://github.com/Sakshi-Vatsa/Meal-Planner

1. Extract this ZIP.
2. Upload index.html and manifest.webmanifest to the ROOT of the repository,
   replacing those two files in the current website.
3. If your GitHub repository does not already have apple-touch-icon.png,
   favicon-32.png, icon-192.png or icon-512.png, upload those too.
4. Commit the changes and let GitHub Pages deploy.
5. Your public URL stays https://sakshi-vatsa.github.io/Meal-Planner/.
   You do not have to rename the GitHub repository to change the app display name.
6. On your phone, remove/re-add the saved Home Screen shortcut if its label
   does not refresh. (Some devices cache the previously installed PWA label.)

Only the displayed name and supporting app metadata are changed.
No private Gmail links, email IDs, or email addresses have been reintroduced.
The original plan repository and its full historical dataset remain separate
from your new dietician's forthcoming plans and recipes.

Meal Planner custom Home Screen icon

1. Open your GitHub Meal-Planner repository on the main branch.
2. Upload the SIX web files from this ZIP to the repository root (where index.html already lives): index.html, apple-touch-icon.png, icon-192.png, icon-512.png, favicon-32.png, manifest.webmanifest.
   Overwrite the existing index.html. README.txt does not need uploading.
3. Commit changes, and wait for the GitHub Pages deployment to finish.
4. On your phone, remove the old Meal Planner Home Screen shortcut (this does not delete the site).
5. Open https://sakshi-vatsa.github.io/Meal-Planner/ in Safari (iPhone) or Chrome (Android).
6. Add to Home Screen / Install App again. The green plate-and-leaf icon should appear.

Note: All meal content from the previously privacy-sanitized index.html is retained.
None of these files includes private Gmail message URLs or message IDs.
